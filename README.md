# Galería Interactiva con JavaScript

Proyecto académico que permite agregar, seleccionar y eliminar imágenes dinámicamente utilizando JavaScript y manipulación del DOM.

## Funcionalidades
- Agregar imágenes mediante URL
- Seleccionar imágenes con clic
- Eliminar imagen seleccionada
- Diseño responsive con CSS Grid
- Publicado en GitHub Pages

## Tecnologías
- HTML
- CSS
- JavaScript
